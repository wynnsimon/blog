# 介绍
elasticsearch 是一款非常强大的开源搜索引擎，可以帮助我们从海量数据中快速找到需要的内容。

elasticsearch 结合 kibana、Logstash、Beats，也就是 elastic stack（ELK）。被广泛应用在日志数据分析、实时监控等领域。
日志数据分析：监控系统运行的日志，用于分析线上运行时的错误
实时监控：监控系统运行时的访问频率，服务器状态等，可以可视化的展示

![](Pasted%20image%2020261008194645.png)
elasticsearch 是 elastic stack 的核心，负责存储、搜索、分析数据。

es 的底层实现是 lucene
Lucene 是一个 Java 语言的搜索引擎类库（jar 包），是 Apache 公司的顶级项目，由 DougCutting 于 1999 年研发。

## 正向索引和倒排索引

### 正向索引
传统的数据库是按照 id 正向索引，但当使用关键字查询时会循环的从前往后逐条比对，当数据量大时会耗费很长时间
![](Pasted%20image%2020261008195121.png)
### 倒排索引
倒排索引将数据额外记录词条和文档的映射，将一条数据分成不同的词条，词条中对应文档的 id 列表，如果某个词条不存在于索引中那么就在后面再创建这个词条并将文档 id 添加进去。在查询时会将查询的内容分词，得到分词后的词条后再去倒排索引中查询，拿到查询结果后再对每个词条的结果集去交集这样就得到了搜索的内容
![](Pasted%20image%2020261008195556.png)

正向索引：先找到文档，再根据文档找词条，看词条是否符合
倒排索引：先查找到词条，然后再根据词条找到文档

## 索引
• 索引(index）：相同类型的文档的集合
• 映射（mapping）：索引中文档的字段约束信息，类似表的结构约束
![](Pasted%20image%2020261008200328.png)


| MySQL    | Elasticsearch | 说明                                                              |
| -------- | ------------- | --------------------------------------------------------------- |
| Table    | Index         | 索引(index)，就是文档的集合，类似数据库的表(table)                                |
| Document | Row           | 文档(Document)，就是一条条的数据，类似数据库中的行(Row)，文档都是 JSON 格式                |
| Column   | Field         | 字段(Field)，就是 JSON 文档中的字段，类似数据库中的列(Column)                       |
| Schema   | Mapping       | Mapping(映射）是索引中文档的约束，例如字段类型约束。类似数据库的表结构(Schema)                 |
| SQL      | DSL           | DSL 是 elasticsearch 提供的 JSON 风格的请求语句，用来操作 elasticsearch,实现 CRUD |

## 分词器

es 自带的分词器只支持英文，如果是中文内容需要使用社区中的其他分词器，最常用的是 ik 分词器

分词器默认只提供通用的字典来进行分词，如果是新兴的词语，比如新的网络用语等就无法正确分词，要让分词器可以正常分割新兴词语需要扩展词库。
分词器在分词时还会产生不必要的词比如 的、了等语气词，联结词等就没必要使用这些词去查询，以及一些敏感词等都需要屏蔽，就需要停用词库
- 扩展词库：ik分词器修改目录中的config目录中的ikAnalyzer.cfg.xml文件的 key 为 ext_dict 的 entry 标签值为扩展词库的与当前文件的相对路径
- 停用词库：ik分词器修改目录中的config目录中的ikAnalyzer.cfg.xml文件的 key 为 stopword_dict 的 entry 标签，值为停用词库的与当前配置文件的相对路径

## mapping 属性
mapping 是对索引库中文档的约束，常见的 mapping 属性包括：
- type：字段的数据类型。字符串：text（可分词的文本）、keyword（精确值，不可分词的文本）、数值：long、integer、short、byte、double、float、布尔：boolean、日期：date、对象：object。没有数组类型，但所有的类型都可以存储多个，也就是说一个类型他表示的就是这个类型以及这个类型的数组
- index：是否创建索引，默认为 true。创建索引的字段会参与搜索
- analyzer：使用哪种分词器
- properties：该字段的子字段

# 操作
ES 中通过 Restful 请求操作索引库、文档。请求内容用 DSL 语句来表示。

**创建索引库和 mapping 的 DSL 语法：**
```
PUT /索引库名称
{
	"mappings": {
		"properties": {
			"字段名"：{
				"type": "text",
				"analyzer":"ik_smart"
			},
			"字段名2"：{
				"type": "keyword",
				"index": "false"
			},
			"字段名3"：{
				"properties": {
					"子字段"：{
						"type": "keyword"
					}
				}
			},
		}
	}
}
```

**查看索引库语法：**
```
GET /索引库名
```

**删除索引库的语法：**
```
DELETE /索引库名
```

**修改索引库：**
索引库和 mapping 一旦创建无法修改，但是可以添加新的字段，语法如下:
```
PUT /索引库名/_mapping
{
	"properties": {
		"新字段名"：{
			"type": "integer"
		}
	}
}
```

**新增文档：**
```
POST /索引库名/_doc/文档 id
{
	"字段 1"："值 1",
	"字段 2"："值 2"，
	"字段 3"：{
		"子属性 1"："值 3"，
		"子属性 2"："值 4"
	}
}
```

**查看文档语法：**
```
GET /索引库名/_doc/文档 id
```

**删除索引库的语法：**
```
DELETE /索引库名/_doc/文档 id
```

**修改文档**
1. 全量修改，会删除旧文档，添加新文档
```
PUT /索引库名/_doc/文档 id
{
	"字段 1"："值 1",
	"字段 2"："值 2",
}
```

2. 增量修改，修改指定字段值
```
POST /索引库名/_update/文档 id
{
	"doc": {
		"字段名"："新的值",
	}
}
```

## 查询
Elasticsearch 提供了基于 JSON 的 DSL（Domain Specific Language）来定义查询。常见的查询类型包括：
1. 查询所有：查询出所有数据，一般测试用。例如：match_all
2. 全文检索(fulltext)查询：利用分词器对用户输入内容分词，然后去倒排索引库中匹配。
3. 精确查询：根据精确词条值查找数据，一般是查找 keyword、数值、日期、boolean 等类型字段。
4. 地理（geo)查询：根据经纬度查询。
5. 复合(compound)查询：将上述各种查询条件组合起来，合并查询条件。

查询的基本语法：
```
GET /indexName/_search
{
	"query": {
		"查询类型"：{
			"查询条件"："条件值"
		}
	}
}
```

### 排序

elasticsearch 支持对搜索结果排序，默认是根据相关度算分来排序。可以排序字段类型有：keyword 类型、数值类型、地理坐标类型、日期类型等。

查询排序的语法：
```
GET /indexName/_search
{
	"query": {
		"查询类型"：{
			"查询条件"："条件值"
		}
	},
	"sort":{
		"排序的条件":"条件值"
	}
}
```

### 分页
elasticsearch 默认情况下只返回 top 10 的数据。而如果要查询更多数据就需要修改分页参数了。elasticsearch 中通过修改 from、size 参数来控制要返回的分页结果:

```
GET /indexName/_search
{
	"query": {
		"查询类型"：{
			"查询条件"："条件值"
		}
	},
	"from":页起始位置,
	"size":页数
}
```

#### 深度分页
ES 是分布式的，所以会面临深度分页问题。
例如查找前 1000 名的数据，在分布式系统中需要对每个服务都查询到前 1000 名，然后再进行排序查到这些数据的前 1000 名，在大厂中服务的数量可能有上千台，使用这种方式的话性能就很高
es 的一页的数量限制小于 10000
