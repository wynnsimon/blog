# 介绍
elasticsearch 是一款非常强大的开源搜索引擎，可以帮助我们从海量数据中快速找到需要的内容。

elasticsearch 结合 kibana、Logstash、Beats，也就是 elastic stack（ELK）。被广泛应用在日志数据分析、实时监控等领域。
日志数据分析：监控系统运行的日志，用于分析线上运行时的错误
实时监控：监控系统运行时的访问频率，服务器状态等，可以可视化的展示

![](Pasted%20image%2020261008194645.png)
elasticsearch 是 elastic stack 的核心，负责存储、搜索、分析数据。

es 的底层实现是 lucene
Lucene 是一个 Java 语言的搜索引擎类库（jar 包），是 Apache 公司的顶级项目，由 DougCutting 于 1999 年研发。

## 正向索引和倒排索引

### 正向索引
传统的数据库是按照 id 正向索引，但当使用关键字查询时会循环的从前往后逐条比对，当数据量大时会耗费很长时间
![](Pasted%20image%2020261008195121.png)
### 倒排索引
倒排索引将数据额外记录词条和文档的映射，将一条数据分成不同的词条，词条中对应文档的 id 列表，如果某个词条不存在于索引中那么就在后面再创建这个词条并将文档 id 添加进去。在查询时会将查询的内容分词，得到分词后的词条后再去倒排索引中查询，拿到查询结果后再对每个词条的结果集去交集这样就得到了搜索的内容
![](Pasted%20image%2020261008195556.png)

正向索引：先找到文档，再根据文档找词条，看词条是否符合
倒排索引：先查找到词条，然后再根据词条找到文档

## 索引
• 索引(index）：相同类型的文档的集合
• 映射（mapping）：索引中文档的字段约束信息，类似表的结构约束
![](Pasted%20image%2020261008200328.png)


| MySQL    | Elasticsearch | 说明                                                              |
| -------- | ------------- | --------------------------------------------------------------- |
| Table    | Index         | 索引(index)，就是文档的集合，类似数据库的表(table)                                |
| Document | Row           | 文档(Document)，就是一条条的数据，类似数据库中的行(Row)，文档都是 JSON 格式                |
| Column   | Field         | 字段(Field)，就是 JSON 文档中的字段，类似数据库中的列(Column)                       |
| Schema   | Mapping       | Mapping(映射）是索引中文档的约束，例如字段类型约束。类似数据库的表结构(Schema)                 |
| SQL      | DSL           | DSL 是 elasticsearch 提供的 JSON 风格的请求语句，用来操作 elasticsearch,实现 CRUD |
